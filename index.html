⚙️ Basic Config

Konfigurasi dasar perangkat jaringan.

1. Apa itu Basic Config?

Basic configuration adalah konfigurasi awal perangkat jaringan agar perangkat dapat digunakan dan berkomunikasi dalam jaringan.

2. IP Address

IP address merupakan alamat logis yang digunakan perangkat untuk berkomunikasi dalam jaringan.

Contoh:

IP Address : 192.168.1.10 Subnet Mask : 255.255.255.0 Gateway : 192.168.1.1 DNS : 8.8.8.8

3. Konsep Gateway

Gateway merupakan perangkat atau alamat yang digunakan untuk menghubungkan jaringan lokal menuju jaringan lain. Biasanya gateway berada pada router.

4. Contoh konfigurasi MikroTik

/ip address add address=192.168.1.1/24 interface=ether1 /ip address print /ip route add gateway=192.168.1.254 /ip dns set servers=8.8.8.8

5. Contoh konfigurasi Cisco

enable configure terminal interface gigabitEthernet 0/0 ip address 192.168.1.1 255.255.255.0 no shutdown exit

💡 Tips Rasyad

Jangan langsung menghafal perintah konfigurasi. Pahami dahulu fungsi setiap perintah.

🔢 Subnetting

Memahami pembagian jaringan IP.

1. Apa itu Subnetting?

Subnetting adalah proses membagi satu jaringan besar menjadi beberapa jaringan yang lebih kecil.

2. Contoh IP

192.168.1.0/24

Prefix /24 memiliki subnet mask:

255.255.255.0

3. Rumus penting

Jumlah host = 2^jumlah bit host - 2 Jumlah subnet = 2^jumlah bit yang dipinjam

4. Contoh /27

Subnet mask /27:

255.255.255.224

Jumlah alamat dalam satu subnet:

2^(32 - 27) = 32 alamat

Host yang dapat digunakan:

32 - 2 = 30 host

5. Blok subnet /27

192.168.1.0 192.168.1.32 192.168.1.64 192.168.1.96 192.168.1.128 192.168.1.160 192.168.1.192 192.168.1.224

6. Contoh subnet pertama

Network : 192.168.1.0 Host : 192.168.1.1 - 192.168.1.30 Broadcast : 192.168.1.31

🔗 Topologi Jaringan

Mengenal bentuk hubungan antar perangkat.

💻 PC 1
🔀 Switch
📡 Router
🌐 Internet

⭐ Star

Semua perangkat terhubung ke perangkat pusat, biasanya switch.

⭐ Bus

Semua perangkat menggunakan satu jalur utama.

⭐ Ring

Perangkat tersusun membentuk lingkaran.

⭐ Mesh

Perangkat memiliki banyak koneksi dengan perangkat lainnya.

⭐ Tree

Topologi bertingkat yang menyerupai struktur pohon.

⭐ Hybrid

Gabungan dari beberapa jenis topologi.

🏷️ VLAN

Virtual Local Area Network.

1. Apa itu VLAN?

VLAN adalah metode untuk membagi satu jaringan fisik menjadi beberapa jaringan logis.

2. Contoh VLAN

VLAN 10 = ADMIN VLAN 20 = GURU VLAN 30 = SISWA

3. Access Port

Access port biasanya digunakan untuk menghubungkan end device seperti PC ke VLAN tertentu.

4. Trunk Port

Trunk digunakan untuk membawa beberapa VLAN melalui satu koneksi.

5. Contoh Cisco VLAN

enable configure terminal vlan 10 name ADMIN vlan 20 name GURU interface fastEthernet 0/1 switchport mode access switchport access vlan 10 interface fastEthernet 0/2 switchport mode access switchport access vlan 20

6. Inter-VLAN Routing

Agar perangkat dari VLAN yang berbeda dapat berkomunikasi, dibutuhkan routing, misalnya menggunakan router atau Layer 3 switch.
